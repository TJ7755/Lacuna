# Accessibility review policy

Require accessible learner workflows. Review [accessibility browser coverage](../../tests/e2e/direction-c-audit.spec.ts)
when changing shared controls.

Use the [manual checklist](../WEBSITE_TEST_CHECKLIST.md) for physical touch, native
IME, assistive technology and actual zoom. Synthetic events and screenshots do
not prove these capabilities. Use British English throughout product copy.

When reviewing disclosures, check Tab traversal and access to the final item in a short desktop
window as well as a full-height one. Capture both motion preferences in browser evidence.
