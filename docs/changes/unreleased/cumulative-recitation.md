- Simple Learn now teaches poetry, speeches and scripts by cumulative recitation: each new line is shown once, then every line of the chunk so far is recited from memory (typed by default, or aloud) and self-marked, with a recitation from the top after each chunk. Chunks follow stanzas or a per-sequence size (4 lines by default). Each line still gets one review per session, and scheduled reviews recite a due line's chunk down to it
