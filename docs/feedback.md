# Feedback form setup

Set `VITE_TALLY_FEEDBACK_FORM_ID` to the identifier after `/r/` in the Tally share
URL before building. Use an empty value to hide feedback. Rebuild after changing it.

Use a required message, optional category and optional contact. Keep the form public
without sign-in, explain the destination and retention in its notice, and enable
the owner’s email notifications. Confirm submission and receipt with a test response
before enabling the live link. Keep responses private in the Tally workspace.
