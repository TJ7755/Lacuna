## Lacuna 0.2.19 Beta

- Practice and Jev recall award graded partial credit: Practice answers scoring at least 60% count as Hard rather than Again.
- Exam technique practice is scheduled on its own, Study serves each worthwhile question once per sitting, and early assessment practice starts only when it is expected to improve recall.
- Course Progress shows the estimated workload for each assessment, how much of it your study budget covers, and informational forecasts for later papers that overlap. Assessment recall predictions no longer move review due dates.
- Scheduling uses the upcoming assessment dates that apply to each course, exam summaries refresh when a deadline passes, and card memory is replayed when optimised scheduling weights change.
- Shared courses are checked in full before an import writes anything.
- The desktop app now runs on Electron 45.

Export a full backup before updating. This release does not change the local database version, so 0.2.18 can still open your data. Backups made by 0.2.15 or earlier no longer import; open them in 0.2.18 and export a new backup first. Installations last opened before database schema v27 refuse to start without changing data; export a backup from the previous build and import it here. Keep devices that sync on the same version.

Desktop packages remain unsigned for this limited beta. Signing, macOS notarisation and wider school rollout still require their separate verification and approval.
