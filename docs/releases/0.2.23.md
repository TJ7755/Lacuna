## Lacuna 0.2.23 Beta

- New lesson cards progress from multiple choice to typed recall. The lesson header counts completed cards, and teachers can require correct spelling for a whole lesson.
- Exam card practice continues across review blocks. Daily allowances reset at local midnight, and the study view shows the full list of priorities and exact due counts.
- Large courses, Cards lists and question-set searches respond faster. Search restores your scroll position when you return from a card.
- Import, backup and recovery screens make it easier to tell what was saved and to recover from failures. Pending editor drafts survive more exit and save-failure paths.
- The desktop sidebar and Touch Mode use simpler controls. The retired AI chat sidebar has been removed.

This limited beta provides unsigned Windows and Linux downloads. macOS packages are built and verified separately.
