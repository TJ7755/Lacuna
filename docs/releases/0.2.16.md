## Lacuna 0.2.16 Beta

- Course library entry points open the Lacuna course library on the web, where you can see each course's provenance and report mistakes. Courses you open there import into the app. New and corrected science, Religious Studies and Cambridge International courses are available.
- Gaps classes: join a class by short code from the dashboard and find joined classes in the sidebar. Gaps reporting to teachers is part of a web trial and is not active in the desktop beta.
- Opt-in Jev marking for typed answers in Study and question sets, with reversible automatic verdicts. Low-confidence marks are saved as Unsure, and self-marking grades stay hidden while automatic marking runs. Jev is a hosted service and currently needs an access code.
- Choose between typed and revealed answers. Captured answers are kept through feedback and Undo.
- Question sets: calmer marking with Lacuna Flow, navigation that animates in its direction of travel, and no routine saving indicator. Search question sets by their content, from Questions and when adding a set to a course path, and replace a saved practice set. Course authors can also search mark schemes. Completed question work keeps its progress when a course update adds further sets or question parts.
- Shared courses: share links are smaller, confirmed imports open on the course page, newly imported courses update automatically, and you choose your study target when joining. You can join a course part-way through.
- Course updates keep lesson tracking, Question Set Concepts and historical Occlusion Concept relationships intact.
- Study: smoother grading and reveal transitions, Continue works from a retained session report, fresh Simple Learn sessions are shuffled once, cards are randomised only when the scheduler rates them equally, and background course refreshes no longer interrupt a session.
- Due review counts are aligned across the dashboard and Study, exam practice can start early, and forecast colours and dates are consistent.
- Saved sync pairings that use the previous relay address are updated on load.
- Many layout, focus and keyboard fixes across toasts, sync confirmations, import, the course settings Lessons tab and the question-set marking toolbar.

Export a full backup before updating. This release upgrades the local database, so you cannot return to 0.2.15 afterwards. Backups from earlier versions still import, but 0.2.15 and earlier will refuse backups made by 0.2.16. Keep devices that sync on the same version.

Desktop packages remain unsigned for this limited beta. Signing, macOS notarisation and wider school rollout still require their separate verification and approval.
