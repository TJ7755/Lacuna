## Lacuna 0.2.16 Beta

- The Lacuna course library: browse published courses from visible entry points, see each course's provenance, report mistakes, and open a course from its cover. New and corrected science, Religious Studies and Cambridge International courses are included.
- Gaps classes for teachers and pupils: create a class with a short code and a generated recovery code, join a class from the dashboard, and find joined classes in the sidebar. Reporting is explicit, consented and end-to-end encrypted, and the reporting day is labelled in UTC.
- Opt-in Jev marking for typed answers in Study and question sets, with reversible automatic verdicts. Jev currently needs an access code. Low-confidence marks are saved as Unsure, and self-marking grades stay hidden while automatic marking runs.
- Choose between typed and revealed answers. Captured answers are kept through feedback and Undo.
- Question sets: search shared question-set content and add it to a course path, replace a saved practice set, and search mark schemes. Completed question work keeps its progress when a course update adds further sets or question parts.
- Shared courses: share links are smaller, confirmed imports open on the course page, newly imported courses update automatically, and you choose your study target when joining. You can join a course part-way through.
- Course updates keep lesson tracking, Question Set Concepts and historical Occlusion Concept relationships intact.
- Study: smoother grading and reveal transitions, Continue works from a retained session report, fresh Simple Learn sessions are shuffled once, cards are randomised only when the scheduler rates them equally, and background course refreshes no longer interrupt a session.
- Due review counts are aligned across the dashboard and Study, exam practice can start early, and forecast colours and dates are consistent.
- Saved sync pairings that use the previous relay address are updated on load.
- Many layout, focus and keyboard fixes across toasts, sync confirmations, import, the course settings Lessons tab and the question-set marking toolbar.

Export a full backup before updating. This release upgrades the local database and writes backups in a newer format. Backups from earlier versions still import, but backups made by 0.2.16 need 0.2.16 or later. Keep devices that sync on the same current version.

Desktop packages remain unsigned for this limited beta. Signing, macOS notarisation and wider school rollout still require their separate verification and approval.
