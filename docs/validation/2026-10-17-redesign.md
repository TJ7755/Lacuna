## Remaining human and device gate

Use [the website checklist](../WEBSITE_TEST_CHECKLIST.md) on one frozen candidate. Record version,
OS/browser/device, input method, theme/accent, app text size, native zoom and motion preference.
Do not substitute viewport resizing for a physical phone, app text scaling for native zoom,
synthetic composing events for a native IME, or DOM assertions for a screen-reader session.

The following evidence has **not** been obtained in this follow-up:

- Novice participant tasks and a recorded comparison baseline.
- Native IME composition, screen-reader use and browser zoom.
- Real microphone/camera/device pairing and live provider/relay availability.
- A fresh complete visual/motion sign-off on the combined, reviewed candidate.

For novice sessions, give these outcomes without explaining which control to use:

| Task                    | Observable completion                                                      |
| ----------------------- | -------------------------------------------------------------------------- |
| Make a first Card       | Create one correct Card, then be ready to enter another without help       |
| Start recommended study | Reach the offered study task, answer and understand the next action        |
| Create a question set   | Add two questions, publish, attempt and self-mark the result               |
| Find content            | Locate a named Card or Question and return to the previous context         |
| Recover from a failure  | Correct or retry a prepared recoverable error while retaining entered work |

Record completion without help, time, facilitator intervention, hesitation/backtracking,
unnecessary key stops and readiness for the next item. Keep raw observations separate from
interpretations. Use equivalent tasks on a named baseline; record order and learning effects.
No participant result or baseline exists yet, so no comparative score is justified.

## Completion decision

Keep #456 and #435 open until the final candidate has successful relevant automated checks,
recorded expert visual/motion review and actual novice-task evidence. Record usability, visual
consistency, keyboard fluency and motion separately, with the evidence behind each judgement.
A green CI run is necessary engineering evidence; it cannot supply the missing human observations.
