# Lacuna

[![CI](https://github.com/TJ7755/Lacuna/actions/workflows/ci.yml/badge.svg)](https://github.com/TJ7755/Lacuna/actions/workflows/ci.yml)

Lacuna is a revision app for secondary students. Its aim is to help learners decide what to
practise next across lessons, school tests and GCSEs. The [focus tracker](https://github.com/TJ7755/Lacuna/issues/902)
holds the delivery plan and evidence.

Use [Lacuna](https://getlacuna.app). Before moving devices or switching from the previous Vercel
address, export a full backup in **Settings → Full backup & recovery** and import it at the destination.
Keep a full backup before replacing existing data.
